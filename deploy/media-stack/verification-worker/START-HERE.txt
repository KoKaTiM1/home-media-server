Home media verification worker - local torrent package 0.3.0

Keep Docker Desktop running in Linux-container mode.
Keep config/, torrent-state/ and EVERY existing data folder:
data/, data-2/, data-3/, data-4/.
Extract this package over the existing HomeMediaVerificationWorker folder.

01-UPDATE-AND-START.cmd
  Checks and installs both included images, safely starts the private local
  torrent service and all four workers, then removes old launchers after success.
  Configuration, identities, progress and pending results stay in place.

02-START-ALL.cmd
  Starts all four workers without loading the image again. Safe to run twice.

03-LOGS.cmd
  Shows combined live logs with a worker name on each line.
  Ctrl+C closes the log view only; workers continue running.

04-STOP-ALL.cmd
  Stops all four workers. All saved data stays in place.

Only four CMD launchers are needed. worker.ps1, SHA256SUMS.json and the image
archive are supporting files; do not delete them before running an update.
The server controls active-job capacity and may pause assignments independently.
The local torrent service has no published LAN port. Windows is optional. The
server keeps verifying independently if this PC is offline, and falls back to
its own verifier if a Windows complete-title job fails.
