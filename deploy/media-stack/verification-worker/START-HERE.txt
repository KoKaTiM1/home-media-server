Windows verification worker 0.4.1

Extract this package over the existing HomeMediaVerificationWorker folder.
Preserve ALL config/, data*/ and torrent-state*/ directories.
Run 01-UPDATE-AND-START.cmd once.

Default capacity: 8 workers, 2 TorrServers.
Edit config/workers.json and run 02-START-ALL.cmd to change counts later.
Default requires Docker Desktop Linux mode and at least 10 GiB VM memory.
The updater checks configuration, credentials, resource budget and image checksum.

03-LOGS.cmd shows combined progress. Ctrl+C only closes logs.
04-STOP-ALL.cmd drains workers and stops torrent backends without deleting data.
Read README.md for capacity limits, fallback and recovery.
